# AvangardRO — клиент для сервера Avangard

AvangardRO — новый клиент игры для сервера **Avangard** (Ragnarok Online). Он заменяет старый `avahi.exe`
с `avaro2.dll`: работает на современных Windows и macOS, не требует dgVoodoo, DirectDraw и патчей, а данные
игры (карты, спрайты, звуки) берёт из файлов `*.grf` установленного клиента Avangard.

В этом репозитории только готовые сборки. Исходный код закрыт.

## Скачать

Последняя версия — на странице **[Releases → Latest](../../releases/latest)**:

| Система | Файл |
|---|---|
| Windows 10/11, 64 бит | `AvangardRO-<версия>-windows.zip` |
| macOS 11+ (Apple Silicon и Intel) | `AvangardRO-<версия>-macos.dmg` или `AvangardRO-<версия>-macos.zip` |

Файлы `latest.json` и `latest.json.sig` нужны клиенту для автообновления, скачивать их не надо.

## Что нужно

- Видеокарта с поддержкой Direct3D 12 или Vulkan (Windows) либо Metal (любой Mac на macOS 11 и новее).
- Около 1,6 ГБ свободного места под данные игры. Старый клиент Avangard **не нужен**: при первом запуске AvangardRO
  сам скачивает данные игры (карты, модели, звуки, музыку) с сервера Avangard и дальше сам их обновляет.
- Файл ключа `avangard.key` — только если сервер шифрует пакеты. Его выдаёт администрация сервера. Если ключ нужен,
  а его нет, клиент сам об этом скажет.

## Установка на Windows

1. Скачайте `AvangardRO-<версия>-windows.zip` и распакуйте в любую папку, например `C:\Games\AvangardRO`.
   В архиве одна папка `AvangardRO-<версия>`.
2. Запустите `avangard.exe`. Откроется окно «Загрузка данных игры»: около 1,5 ГБ, с прогрессом. Загрузку можно
   остановить и потом продолжить с того же места. Данные ложатся в папку `data` рядом с `avangard.exe`, каждый файл
   проверяется по подписи и контрольной сумме.
3. После загрузки откроется экран входа. Дальше клиент при каждом запуске в фоне докачивает только изменённые
   данные (обычно меньше мегабайта).
4. Если у вас уже есть старый клиент Avangard, можно скопировать `avangard.exe` и остальные файлы архива в его
   папку (где лежат `weath.grf`, `adata.grf`, `sdata.grf`) — тогда клиент играет на его GRF и ничего не качает.
   Переключиться на скачиваемые данные: `data_source = "packs"` в `avangard.toml`.
5. Если сервер шифрует пакеты, положите `avangard.key` рядом с `avangard.toml` (он появится рядом с `avangard.exe`).
6. Подробности — в `README.txt` внутри архива, все настройки с пояснениями — в `avangard.toml.example`.

Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Установка на macOS

1. Скачайте `AvangardRO-<версия>-macos.dmg`, откройте его и перетащите `AvangardRO.app` в «Программы».
2. При первом запуске откроется окно «Загрузка данных игры» (около 1,5 ГБ), данные ложатся в
   `~/Library/Application Support/AvangardRO`. Если на Mac уже есть папка старого клиента с GRF (`~/AvangardRO`,
   `~/Games/AvangardRO`, `/Applications/AvangardRO` или рядом с `AvangardRO.app`), клиент возьмёт данные из неё.
3. Первый запуск: сборка не заверена Apple, поэтому щёлкните `AvangardRO.app` правой кнопкой → «Открыть» →
   «Открыть». Либо в Терминале: `xattr -dr com.apple.quarantine /Applications/AvangardRO.app`.
4. Настройки (`avangard.toml`), журнал (`logs`) и ключ `avangard.key`, если он нужен, лежат в
   `~/Library/Application Support/AvangardRO`. Снимки экрана сохраняются в `~/Pictures/AvangardRO`.

## Обновления

Клиент сам проверяет новые версии: когда открывается экран входа, он в фоне скачивает описание последнего выпуска.
Вход в игру при этом не задерживается. Если есть новая версия, откроется окно «Обновление клиента» со списком
изменений:

- «Обновить» — скачать и установить обновление, после чего клиент перезапустится сам;
- «Позже» — не обновляться до следующего запуска;
- «Отмена» во время загрузки — прервать загрузку. Если загрузка зависла, клиент прервёт её сам.

Каждый выпуск подписан ключом разработчика (ed25519). Клиент проверяет подпись `latest.json`, а затем размер и
контрольную сумму SHA-256 скачанного архива и устанавливает обновление, только если всё совпало. Обновление заменяет
только файлы клиента. Настройки, ключ, журналы, снимки экрана, GRF и папки `BGM` и `AI` оно не трогает. Если
обновить не удалось, клиент покажет причину и ссылку на страницу загрузок.

Отключить проверку обновлений можно строкой `update_check = false` в `avangard.toml`.

Обновиться вручную можно всегда. На Windows скачайте новую версию со страницы Releases и скопируйте содержимое
папки `AvangardRO-<версия>` поверх старых файлов. На macOS замените `AvangardRO.app`.

## Проблемы

Если клиент закрылся с ошибкой, в папке `logs` появится `crash-ГГГГММДД-ЧЧММСС.txt`. На Windows папка `logs`
лежит рядом с `avangard.toml`, на macOS — в `~/Library/Application Support/AvangardRO`. Пришлите этот файл
администрации сервера вместе с описанием того, что вы делали. Пароль и ключ шифрования в журнал не пишутся.
